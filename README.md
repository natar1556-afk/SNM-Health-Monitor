# Fitness Tracking MERN App

## Quick Start

### Backend
1. `cd backend`
2. Copy `.env.example` to `.env` and set `MONGO_URI` + `JWT_SECRET`.
3. `npm install`
4. `npm run dev`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`

The frontend expects the backend at `http://localhost:5000`.
Set `VITE_API_URL` in `frontend/.env` to change it.
